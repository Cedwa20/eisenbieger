# Eisenbieger

Offlinefähige Fitness-Web-App mit Trainingsplänen, Übungsbibliothek, Trainingsprotokoll und Statistiken.

- **Haupt-App:** https://cedwa20.github.io/eisenbieger/
- **DEV-App:** https://cedwa20.github.io/eisenbieger/dev/
- **Aktuelle freigegebene Version:** 1.3.0 (23.11.2026)
- **Änderungshistorie:** [CHANGELOG.md](CHANGELOG.md)

## Entwicklung

Änderungen werden im Branch `development` vorbereitet und unter `/dev/` im Veröffentlichungsbranch `gh-pages` getestet. Erst nach Freigabe gelangen sie nach `main` und in die produktive Veröffentlichung.

**Hinweis:** Trainingsdaten werden lokal im jeweiligen Browser gespeichert. Regelmäßige JSON-Backups sind empfohlen.
